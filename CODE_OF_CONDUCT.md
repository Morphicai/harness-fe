# Code of Conduct

Harness-FE adopts the [Contributor Covenant, version 2.1][cc] as its code of
conduct. Every participant in our issues, pull requests, discussions, and
community spaces is expected to read and follow it.

The short version: be respectful, be patient, assume good faith. Disagree on
ideas, not on people. If a behaviour would make a colleague uncomfortable in a
professional setting, it almost certainly doesn't belong here either.

## Scope

This Code applies inside every Harness-FE space — the GitHub repository, issues
and pull requests, discussions, related community channels, and any in-person
or online event where someone represents the project.

## Reporting

If you experience or witness behaviour that violates this Code, please report
it privately to the maintainers through GitHub:

- Open a [private security advisory](https://github.com/Morphicai/harness-fe/security/advisories/new)
  on this repository — it routes only to maintainers and is not visible to
  the public. (We use the same channel for conduct reports so we have a
  single, auditable, private inbox.)

Reports are read by the project leads only and handled confidentially. We aim
to acknowledge every report within three working days.

If a maintainer is the subject of a report, file the advisory anyway — other
maintainers will be looped in. All maintainers who handle reports are
expected to recuse themselves from cases involving people they have a close
personal or professional relationship with.

## Enforcement

Maintainers may take any action they judge appropriate, up to and including
temporary or permanent removal from project spaces. Decisions follow the
[Enforcement Guidelines][cc-enforcement] published with Contributor Covenant
2.1.
